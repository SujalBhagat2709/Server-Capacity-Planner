# Server Capacity Planner

## Overview

Server Capacity Planner is a Python command-line application that helps administrators monitor server resource utilization. It tracks CPU, RAM, and storage usage, calculates remaining capacity, identifies critical servers, and provides an overall infrastructure capacity summary.

---

## Features

- Add Server Details
- CPU Utilization Tracking
- RAM Utilization Tracking
- Storage Utilization Tracking
- Remaining Capacity Calculation
- Server Health Classification
- Critical Server Detection
- Capacity Summary
- Interactive Menu
